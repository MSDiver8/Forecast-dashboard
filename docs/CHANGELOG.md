## 2026-10-07 — MVP, первая сборка

- Каркас: `pyproject.toml` (uv, ruff, pytest), `src/fdash/` (ingest, store, core, api, cli), миграция `001_init.sql`, справочник `config/indicators.yaml`.
- Коннекторы и паспорта источников (`docs/sources/`): EIA STEO, EIA RBRTE (факт Brent вместо недоступного FRED), Всемирный банк CMO, Банк Англии MPR, ЕЦБ MPD (нефть и еврозона), макроопрос Банка России, МВФ WEO, Банк России (факт ИПЦ дек./дек. и ключевой ставки).
- Семь бенчмарк-моделей (RW, RWD, RWS, RWDS, TS, MA, ARIMA) с интервалами 80/95 % и кэшем в `benchmark_runs`.
- API на FastAPI и интерфейс на React + Recharts в стиле платформы НЦСЭД: сравнение, каталог показателей, состояние данных; винтажи «последний», «на дату», вручную; таблица с отклонениями и экспортом CSV/XLSX.
- CLI: `fdash ingest`, `fdash rebuild`, `fdash status`, `fdash serve`.
- ТЗ, раздел 5: схема приведена к реализации (диапазоны `lower/upper`, `data_cutoff`, контрольная сумма, роль источника, частота как свойство наблюдения).
