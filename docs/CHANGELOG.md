## 2026-10-14 — «Оценка точности»: панель агентств и моделей, факт по месяцам, метрики

- Вкладка переименована в «Оценка точности» и устроена как сравнение показателя: слева период прогноза, окно публикации с датами, версия факта, агентства и базовые модели галочками; отмеченные ряды попадают на график, в таблицу и в метрики.
- График «по периодам»: прогноз стоит над периодом, на который сделан, черта до факта — ошибка; факт за период — отрезок или, для инфляции «декабрь к декабрю», точка декабря; под ним линия факта по месяцам или кварталам (поле `context` справочника), если такой ряд есть. Второй вид — «как менялся прогноз на период» по датам публикации, с путями моделей. Масштаб колесом и ползунком, «Весь период», PNG.
- Базовые модели оцениваются на факте, известном на конец окна; частоту оценки выбирает пользователь (для средних — более частый ряд с усреднением до периода, для «декабрь к декабрю» — значение декабря месячной инфляции); окно последних N точек у TS, RWD, RWDS и `q` у MA. TS получил параметр окна. Кэш расчётов вынесен в `store/model_runs.py` и общий с первой вкладкой.
- Метрики точности: число периодов, MAE, RMSE, MAPE (не считается при факте меньше 1), ME, MAE / MAE RW; определения во всплывающих подсказках «i»; величина ошибки в таблице подсвечена одним цветом. Оценочные слова удалены из интерфейса; «Обучать до» → «Оценивать до»; на странице «Методика» обновлены абзацы о моделях и оценке точности.
- Данные: месячная инфляция г/г и средняя ключевая ставка за месяц из файлов Банка России; Евростат переведён на наборы ECOICOP ver. 2 (`prc_hicp_ainr` — годовой факт, `prc_hicp_minr` — месячный темп), прежние наборы заморожены с февраля 2026 года; новый источник — Росстат «ВВП кварталы» (паспорт `docs/sources/rosstat_gdp_q.md`, доступ с сертификатами Минцифры), он же показан в реестре источников. Новый показатель справочника `cpi_yoy_m`.
- API: `POST /api/evaluation` (агентства, модели с параметрами, частота оценки, путь прогноза по запросу) вместо `GET /api/evaluation/{id}`.
- ТЗ v0.5: разделы 1, 3, 4.2, 5, 6, 8, 11. CLAUDE.md: решения 14 октября.
- Открытые вопросы: условия повторного использования данных Росстата на сайте не указаны — нужна оценка заказчика.

## 2026-10-13 — раздел «Оценка точности прогнозов»

- Раздел переделан по согласованному макету, вкладка переименована в «Оценка точности прогнозов». Вместо средних ошибок по горизонтам — прямое сравнение опубликованных прогнозов с фактом, ставшим известным позже.
- График «Как менялся прогноз на период»: прогнозы источников по датам публикации, факт, подсвеченное окно сравнения, выбранные прогнозы с пунктиром до факта; справа — значения и ошибки за период.
- Окно публикации задаётся датами («с 01.07.2023 по 31.12.2023»), из окна берётся последний выпуск источника. Годовые ряды — четыре полугодовых окна (по умолчанию — второе полугодие предыдущего года), квартальные и месячные — по кварталу и по месяцу.
- Таблица «Прогнозы и факт за все годы»: у каждого значения дата выпуска (приблизительные даты — с «≈»), ошибка в п.п. или в единицах показателя; периоды без факта — серым.
- Наивный прогноз — факт последнего периода, закончившегося до начала окна, — ориентир в таблице и итоге.
- Итог «Кто точнее»: средняя ошибка по модулю с формулой, «занижал/завышал в k из n», «точнее наивного»; считается по общим периодам источников, у которых не меньше 3 проверенных периодов, остальные — «мало данных».
- Переключатель факта: последняя оценка или первая оценка из архива.
- API: `/api/evaluation/{id}` — параметры `window` (0–3) и `fact` (`latest` | `first`), новый формат ответа.
- Открытые вопросы: ТЗ (разделы 1 и 11) описывает прежний вариант раздела — правка предложена заказчику; на странице «Методика» устарел абзац про RMSE и смещение по горизонтам.
