# Росстат: ВВП по кварталам (факт)

- **Роль:** фактический рост ВВП России по кварталам, % к соответствующему кварталу предыдущего года (`gdp_yoy_q`, Россия). На вкладке «Оценка точности» показателя «Рост ВВП России» — линия факта по кварталам под годовым фактом; ошибки годовых прогнозов считаются только от годового факта.
- **Страница:** https://rosstat.gov.ru/statistics/accounts, раздел «Валовой внутренний продукт», ссылка «ВВП кварталы (с 1995 г.)». Имя файла меняется с годом (`/storage/mediabank/VVP_kvartal_s-1995-2026.xlsx` на 14 октября 2026), поэтому адрес берётся со страницы по шаблону `VVP_kvartal_s…xlsx`.
- **Доступ:** сайт открывается только по TLS с сертификатом «Russian Trusted Sub CA» Минцифры. Проверено 14 октября 2026: без него запрос завершается ошибкой проверки сертификата. Корневой и промежуточные сертификаты Минцифры (официальная раздача `gu-st.ru/content/Other/doc/russian_trusted_root_ca.cer`, `russian_trusted_sub_ca.cer`; промежуточный 2024 года — `nuc-cdp.digital.gov.ru/cdp/subca_ssl_rsa2024.crt`, адрес указан в сертификате сайта) лежат в `src/fdash/ingest/certs/russian_trusted_ca.pem` и добавляются к системному списку доверия только для запросов к Росстату. Отпечатки SHA-256: корневой `D2:6D:2D:02:…:CA:8E:CF:31`, промежуточный 2024 года `21:55:78:50:…:7D:88:A3:F2`, промежуточный 2022 года `BB:BD:E2:10:…:D8:B3:FD:9B`.
- **Ряд:** листы с заголовком «Индексы физического объема валового внутреннего продукта (в процентах к соответствующему кварталу предыдущего года)»: лист `11` — 1996–2011 годы, лист `12` — с 2012 года (методология СНС 2008, переоценки по базовым таблицам 2011, 2016 и 2021 годов; с 2022 года без данных по ДНР, ЛНР, Запорожской и Херсонской областям — сноска 2 файла). Строки: годы (`2012`, `20222)` — год со сноской), кварталы («I квартал» … «IV квартал»), значения индекса. Темп роста = индекс − 100. При пересечении листов берётся более поздний.
- **Проверено 14 октября 2026:** ответ 200, `Last-Modified: Fri, 11 Sep 2026`, 115 224 байта; на странице дата файла 11.09.2026. Ряд с I кв. 1996 по II кв. 2026; II кв. 2026 — 101,31 (рост 1,31 %), I кв. 2026 — 99,85.
- **Винтажи:** архива версий нет; выпуск — дата `Last-Modified` файла, новый выпуск сохраняется, только если файл изменился. Сроки публикации — на последнем листе файла (за III кв. 2026 — не позднее 11 декабря 2026 года).
- **Лимиты:** не обнаружены; один файл на загрузку.
- **Лицензия:** на странице указан копирайт Росстата, явных условий повторного использования нет. Данные — официальная статистика, используются со ссылкой на источник; условие ждёт подтверждения заказчика.
