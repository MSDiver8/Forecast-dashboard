# BEA, NIPA Table 1.1.1 (факт роста ВВП США)

- **Роль:** эталонный факт для показателя «Реальный ВВП США, % к предыдущему кварталу в годовом выражении».
- **Почему не FRED.** FRED (`A191RL1Q225SBEA`) перепубликует этот ряд BEA. CSV-адреса FRED из нашей сети не отвечают (7–13 октября 2026), API FRED требует ключ, привязанный к учётной записи заказчика: создать её за заказчика нельзя (подтверждение по e-mail, принятие условий). Поэтому факт берётся у первоисточника без ключа.
- **Файл:** `https://apps.bea.gov/national/Release/XLS/Survey/Section1All_xls.xlsx` — все таблицы раздела 1 NIPA, ≈4 МБ. Проверено 13 октября 2026: ответ 200, `last-modified: 30 Sep 2026`.
- **Структура:** лист `T10101-Q` — «Table 1.1.1. Percent Change From Preceding Period in Real Gross Domestic Product», строка 2 «[Percent] Seasonally adjusted at annual rates», строка 5 «Data published September 30, 2026». Строка с `Line` в столбце A — кварталы `1947Q2` … ; строка с кодом `A191RL` в столбце C — «Gross domestic product». Разбор ищет строки по `Line` и коду, а не по номеру.
- **Определение:** рост реального ВВП к предыдущему кварталу в годовом выражении (SAAR), %. Тот же ряд в реестре BEA `SeriesRegister.txt`: `A191RL, "Gross domestic product", "Fisher Quantity Index", "Percent change, annual rate"`.
- **Винтажи:** архив прошлых версий файла не публикуется. Винтаж — дата «Data published»; новый выпуск сохраняется, только когда файл изменился.
- **Лицензия:** материалы федерального правительства США, общественное достояние (17 U.S.C. § 105); источник указываем.
- **Образец:** `tests/fixtures/bea_nipa/Section1All_T10101-Q.xlsx` — лист `T10101-Q` из выпуска 30.09.2026 (остальные листы удалены).
