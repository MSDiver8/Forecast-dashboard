# Банк России: факт по инфляции и ключевой ставке

- **Роль:** эталонный факт для показателей «Инфляция, декабрь к декабрю» (Россия) и «Ключевая ставка, в среднем за год»; месячные ряды — линия факта на вкладке «Оценка точности» и ряды для оценки базовых моделей по месяцам.
- **Инфляция:** таблица «Инфляция и ключевая ставка Банка России», https://www.cbr.ru/hd_base/infl/. Выгрузка в XLSX: `https://www.cbr.ru/Queries/UniDbQuery/DownloadExcel/132934?FromDate=01%2F01%2F2015&ToDate=<MM%2FDD%2FYYYY>&posted=False`. Столбцы: «Дата» (`MM.YYYY`), «Ключевая ставка, % годовых» (на конец месяца), «Инфляция, % г/г», «Цель по инфляции». Инфляция — данные Росстата, которые публикует Банк России. Значение за декабрь — это инфляция «декабрь к декабрю предыдущего года».
- **Ключевая ставка по дням:** веб-сервис DailyInfo, SOAP 1.2, `POST https://www.cbr.ru/DailyInfoWebServ/DailyInfo.asmx`, метод `KeyRateXML(fromDate, ToDate)`; ответ — элементы `KR` с `DT` и `Rate` за рабочие дни. GET-вариант метода не поддерживается (ответ «Формат запроса не распознан»).
- **Средняя ставка за год «с учётом выходных дней»** (определение макроопроса Банка России): в выходные и праздники действует последняя установленная ставка; среднее берётся по всем календарным дням года. Считаем только завершённые годы.
- **Месячные ряды (с 14 октября 2026):** инфляция за месяц к тому же месяцу прошлого года (`cpi_yoy_m`, все месяцы таблицы; значение за декабрь совпадает с годовым «декабрь к декабрю») и средняя ключевая ставка за месяц по календарным дням (`key_rate_avg`, частота M; только завершённые месяцы, первый — октябрь 2013 года). Берутся из тех же файлов, новых запросов нет.
- **Не покрыто:** ИПЦ в среднем за год (`cpi_avg`) нельзя точно получить из месячных темпов г/г — нужен ряд индексов Росстата (этап 2).
- **Винтажи:** архива версий нет; выпуск — дата загрузки, новый выпуск сохраняется, только если файлы изменились.
- **Лицензия:** материалы сайта Банка России, со ссылкой на источник.
- **Образцы:** `tests/fixtures/cbr_stats/`.
