# EIA, Europe Brent Spot Price FOB (факт Brent)

- **Роль:** эталонный факт для показателя «Цена нефти Brent».
- **Почему не FRED.** Решение заказчика — FRED `MCOILBRENTEU`. 7 октября 2026 адрес `https://fred.stlouisfed.org/graph/fredgraph.csv?id=MCOILBRENTEU` не отвечал: таймаут 90 с, по HTTP/2 — ошибка потока, хотя главная страница FRED открывалась. FRED перепубликует ряд EIA `RBRTE`; первые значения совпадают с CSV FRED из прототипа (05.1987 — 18.58, 06.1987 — 18.86). Поэтому факт берётся у первоисточника. Требует подтверждения заказчика.
- **Страница ряда:** https://www.eia.gov/dnav/pet/hist/LeafHandler.ashx?n=PET&s=RBRTE&f=M — строки «Release Date: M/D/YYYY» и «Next Release Date». Обновляется еженедельно.
- **Файлы:** `https://www.eia.gov/dnav/pet/hist_xls/RBRTEm.xls` (месячный, с 05.1987) и `RBRTEa.xls` (годовой). Формат XLS (Excel 97), лист `Data 1`: строка 2 — `Sourcekey RBRTE`, данные с строки 4, столбец A — дата Excel, столбец B — долл./барр.
- **Годовой ряд** — официальное среднее по дням, а не среднее 12 месяцев: 2021 — 70.86 против 70.68 среднего месяцев, 2025 — 69.14 против 69.10. Для годового факта берём `RBRTEa`.
- **Винтажи:** у источника нет архива прошлых версий. Винтаж — дата выпуска со страницы ряда; новый выпуск сохраняется, только когда меняется эта дата.
- **Лицензия:** public domain (U.S. Government).
- **Образцы:** `tests/fixtures/eia_brent_spot/`.
